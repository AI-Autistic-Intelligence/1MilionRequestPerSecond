Ferrox Ecosystem Benchmark

Simulating 1 Million RPS Workload (8.0 vCPU limits)

Overview & Methodology

This benchmark measures the performance of 5 different backend frameworks under a Dockerized environment. Each backend instance (replica) was constrained to 8.0 vCPUs to allow Node.js and Rust to fully leverage multiple threads and connection pooling, ensuring they can express their maximum potential without OS throttling.

Each request performs:

  • A Redis INCR command for IP-based rate limiting (1000 max).
  • A Postgres SELECT query reading a random record from a 100k seeded table.
